# 03: Smart Inventory Depletion Alerts, BOM Wastage Variance Analytics & Inventory Intelligence View (Tab 3)

**What to build:** Branch managers and salon owners can open **Tab 3 (Cảnh báo Kho thông minh & Hao hụt BOM)** on the Executive Dashboard (or via the sidebar shortcut) to monitor chemical stock depletion risks and audit `BOM Wastage` across the selected branch and period. The Smart Inventory Alert panel classifies branch products into three actionable alert levels—`OUT_OF_STOCK` (zero sealed units and zero opened volume), `LOW_STOCK` (`Sealed Units <= min_stock_alert_units`), and `NEAR_THRESHOLD` (`Sealed Units == min_stock_alert_units + 1` or estimated days until depletion $\le 7$ days based on daily consumption burn rate)—and provides a one-click **"Nhập kho ngay"** button that opens the `Stock In` modal pre-selected for that product. Below the alerts, the `BOM Wastage` table compares each chemical product's aggregated **Standard BOM Volume** (`ml`/`g` expected for all `PAID` services in the period) against **Actual Consumed Volume** (combining `SERVICE_CONSUMPTION` deductions and negative `Stock Adjustment` audit losses), displaying wastage volume (`ml`/`g`), percentage overrun (`%`), and monetary loss in VND.

**Blocked by:** 01: Realized Profit & Loss (P&L) Engine, Cost Snapshots & Executive Command Center Dashboard (Tab 1)
